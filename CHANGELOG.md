# Changelog

All notable changes to ADRP will be documented here.

## 0.1.0 - 2026-10-01

### Added

- Ape Decision Record Profile v1 and source-sidecar schema.
- Standard-library `adrp` CLI.
- Validation, canonical fingerprints, lifecycle assessment, immutable
  ratification, Markdown rendering, verbatim imports, and source refresh checks.
- Record inspection, set verification, scope resolution, autonomy evaluation,
  and relationship graphs.
- ADRP agent with write, read, import, quality, resolve, ratify, and drift
  skills.
- CAFE(S) source-intake, intent-fitness, record-fitness, and
  projection-fitness assessments with a deterministic validation contract.
- Human and agent documentation with a schema-valid worked example.
- Unit, integration, resolution, tamper, lifecycle, and packaging tests.
